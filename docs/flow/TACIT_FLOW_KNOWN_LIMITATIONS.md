# Known limitations — material release blockers

- **No real Meet capture/playback proof.** Headless extension loading is not a user toolbar grant; actual source isolation and audibility remain blocked on a consenting human test. No two-device end-to-end claim.
- **Semantic quality inadequate.** Original Flash-Lite 9/12 binary-change cases; new stress set 4/8. All eight stronger 3.8 Flash requests exceeded five seconds. Exact quotation grounding does not fix missed or wrong relationships. Warnings say POSSIBLE and remain optional/experimental. No clinical/reliability gate passed.
- **No demonstrated effort reduction.** No measured A/B/C user study, keystrokes or response/resume timings. Comparator results are development observations with limitations documented. Cannot promise an MLH award or Gemini superiority.
- **Provider terms pending.** Real meeting text stays disabled until the actual project terms/billing are verified and participants separately agree. Cloud transcription is not implemented. No face/video upload.
- **Recognition remains unvalidated.** Saved Flow drafts are authored text. Current raw/N-best review remains exact and separately authorized; the selected question/context warning can accompany it, but stale recognized candidates cannot be resumed as speech. No saved-recognition authorization shortcut, context-based candidate selection or synthetic alternatives. Editing/correction preserves existing provenance.
- **Local STT is not perfect verbatim capture.** Whisper may normalize numbers, miss words/self-corrections or hallucinate. Only three synthetic speech files were measured; no real-call WER, noise/overlap or speaker identity evidence. Provisional results are not used as semantic sources.
- **Lifecycle/hardware testing incomplete.** Headphones/Bluetooth switch, real Chrome crash/restart/navigation, permission revocation, simultaneous capture/output and app crash need human tests. Worker startup cancellation and server framing are tested in software only.
- **Accessibility not certified.** Native labeled controls, keyboard paths, stable editor ownership, no timed decisions, reduced-motion conventions and 44-point Flow buttons are implemented. VoiceOver/full keyboard/navigation/visual burden need actual use. Flow expands deliberately to at most 460×540; compact/Peek geometry unchanged. No switch/eye-gaze validation.
- **UI evidence is diagnostic.** Some AppKit-rendered fixtures omit heading glyphs. The saved/typed speech bar is kept visible outside scrolling content, but real native interaction and screenshots still need human validation. Remote echo may be transcribed; no reliable echo/speaker separation is claimed.
- **Candidate distribution only local.** Ad-hoc signature, no Developer ID/notarization. Existing research-weight license limitations remain. Dependency symlinks and read-only model references require the local setup; no self-contained installer.
- **Concurrent stable/candidate shortcuts unverified.** Use visible Stop during dual-app testing. The candidate does not replace or restart stable TACIT, but OS shortcut collisions need validation before side-by-side use.
- **Memory is bounded/session-local, not secure erasure.** Provider cancellation may still be processed/billed; abort usage is unknown. No permanent transcript/history/export feature. The runtime has no explicit user transcript-editing UI; incorrect transcription requires inspecting/dismissing source and using ordinary communication.
- **No active consent identity verification for remote participants.** Checkbox records the user's confirmation, not independent consent from every participant. Source claims depend on the trusted installed extension; a malicious same-user local process is outside the browser-origin boundary.
