# Discovery, prior art and build decisions

The intended advantage is preserving participation during response preparation. It is not assuming the user cannot understand the meeting. [ASHA AAC](https://www.asha.org/practice-portal/professional-issues/augmentative-and-alternative-communication/) discusses individualized systems and partner wait time; [ASHA dysarthria](https://www.asha.org/practice-portal/clinical-topics/dysarthria-in-adults/) distinguishes speech production from language impairment. Different access, language, motor, hearing and attention needs require user choice.

[COMPA, CHI 2024](https://www.cs.cmu.edu/~jbigham/pubs/pdfs/2024/compa.pdf) already studies conversation context and co-occurring talk during AAC composition. [Conversational Agency, CHI 2020](https://www.cs.cmu.edu/~jbigham/pubs/pdfs/2020/aac-agency.pdf) broadens agency beyond typing rate. [AAC experts informing agent design](https://www.microsoft.com/en-us/research/wp-content/uploads/2026/01/Beneteau-2026-AAC-and-Agentic-Design.pdf) informs control/ownership concerns. [Project Converse](https://ubwp.buffalo.edu/converseaac/projects/) investigates repair/turn timing. These motivate sparse source-backed assistance; they do not validate TACIT's benefit.

Public project pages are self-reports: [AACE It!](https://devpost.com/software/aace-it) combines AAC phrase suggestions/TTS/practice; [CommuniCare](https://devpost.com/software/communicare-x35k2b) focuses on caregiver-to-picture-board generation. We did not independently validate their performance. TACIT should demonstrate a different workflow rather than claim to be the first AAC/Gemini system. Prior Referent Bridge P0 was rejected: deterministic chips tied its priority examples and modeled actions increased. No reference-chip relaunch is justified.

## Selection rubric

For each row: barrier; required signals; Gemini role; user decision; simpler alternative; hypothesized effort/error benefit; attention cost; safe demo/test; release decision. Benefits below are hypotheses unless explicitly marked implemented mechanics. KEEP means included in the coherent candidate, not validated for promotion. EXPERIMENT means not integrated as a promised feature. No clinical effectiveness claimed.

| Context change guard | Underlying proposal changes mid-composition; source revisions + selected anchor | Relationship + exact before/after evidence; user chooses whether/how to respond | Lexical correction baseline; prevents stale-context mistakes if useful, but false warnings cost attention | Frozen synthetic comparisons then consenting Meet; **EXPERIMENT** semantic quality below target; implemented behind explicit opt-in |
| Save/resume three turns | Lost work when topics move; user draft + selected source | No Gemini needed; user picks turn to resume/discard | Bounded deterministic queue; avoids retyping; one saved-turn row | Test no word loss through interruptions/pause; **KEEP**, implemented mechanics |
| Rejoin earlier question (A) | Missed opportunity; selected earlier source | Optional reference wording is unnecessary for first version; user picks original question | Editable deterministic re-entry template; no API wait; a deliberate action | Compare resume/re-entry actions vs manual recreation; **KEEP**, generic editable request, no invented topic |
| Repeat/clarify (B) | Repair takes too long; user-selected question | No inference needed for generic repair; user decides to ask | Editable templates preserve answer; one collapsed recovery group | No speech until explicit Speak; **KEEP**, implemented |
| Partner coordination (C/D) | Others move on while user writes; deliberate Hold action | No Gemini needed; no inference of desired interruption | Existing Hold My Turn; uses existing authorization and preserves text | Listener hears exact hold once; **KEEP existing**; no automatic hold |
| Correct a misunderstood message (E) | Rebuilding previous thought; last approved message + user's correction | Could link remote paraphrase to prior message; user supplies correction meaning | Existing last-message reuse + user correction template; avoids opinion inference | Two-device repair with exact last delivery; **EXPERIMENT**, additional inference not justified yet |
| Meaning Contrast (F) | Genuine N-best differs consequentially; actual candidate IDs/text | Annotate only; user selects whole candidate | Lexical diff/negation highlights first; no extra stage for simple can/can't | Independent real-candidate comparison; **EXPERIMENT**, no fabricated examples/candidates integrated |
| Participation queue (G) | Two concurrent thoughts; explicit source/draft links | No Gemini needed to preserve content | Three-slot deterministic store, no eviction | Interrupt/resume each without word loss; **KEEP**, implemented |
| **Topic returns radar** (new 1) | A saved thought becomes relevant again; new turns + saved source | Propose a citation-backed topic return; user elects to reopen it | Shared-word baseline; may save search, but false return pings distract | 20 unrelated/return exchanges, precision/actions; **EXPERIMENT**, promising next semantic test |
| **Question-parts rail** (new 2) | Several questions asked before answer ready; exact source spans | Split explicit subquestions; never fill answers or mark opinions | User-selected source bookmarks; may prevent losing a second question, adds tracking | Two/three-part questions, missed-part rate and visual burden; **EXPERIMENT** |
| **Repair receipt** (new 3) | Partner paraphrases user's approved statement incorrectly; prior approved words + newer source | Propose whether paraphrase changes a constraint; user decides if it is misunderstanding | Deterministic number/negation comparison; can prevent commitment errors, false positives costly | Balanced faithful/unfaithful paraphrases; **EXPERIMENT**, no automatic correction speech |
| **Scope checkpoint** (new 4) | 'Only for Friday' becomes 'all week'; selected anchor + later wording | Distinguish scope expansion from a separate proposal; user chooses relevance | Lexical scope cues then semantic annotation; meaningful beyond time regex, one warning | Blinded scope/minimal-pair dataset vs lexical baseline; **EXPERIMENT** |

| Autonomous replies/silent VSR rewrite | Apparent speed at expense of ownership | Unacceptable user-position inference | Preserve raw review/manual tools | **REJECT**, violates product constraints |

## Judging thesis

The most compelling *testable* moment: the user chooses an old question, starts their own answer, the source changes indirectly, and TACIT surfaces exact evidence while preserving the original wording. A plain Gemini chat can discuss a pasted transcript; it does not by itself capture the selected source, version transcripts, preserve independent drafts during interruptions, validate current citations, maintain genuine VSR identities or enforce voice authorization/Stop. These are system capabilities, not claims that Gemini alone is irreplaceable. The current experiments do **not** establish a superior semantic model or award-worthy clinical outcome. Show evidence and limits rather than a fabricated success.
